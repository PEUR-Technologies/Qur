# Qur logo kit (v1.0)

Qur by PEUR Technologies. The mark is a QR finder eye whose tail is Peur's triangle, so together they make a Q.
Colours: Black #000000, White #FFFFFF.

## Folders
- svg/   Vector masters (use these first). Symbol, small-size symbol (below 48 px), horizontal and stacked lockups, wordmark, icon tiles. Black and white versions. All letterforms are outlined paths, so no fonts are needed.
- png/   Flat transparent PNGs at 512/1024/2048 (symbol) and 2400 px wide (lockups).
- 3d/    The puffy renders in the Peur style. Transparent PNGs in white and black, plus versions on solid black or white. For hero, social and presentation use only, not for small sizes.
- icons/ favicon.ico (16/32/48), favicon.svg, apple-touch-icon, 192/512 PWA icons, maskable icon, 1024 app icon (3D), site.webmanifest and a <head> snippet.
- qur-brand-board.png      Presentation board with mockups.
- qur-logo-usage-guide.pdf One-page usage rules.

## Notes
- The wordmark "qur" is custom drawn, so always use the supplied files.
- The 3D look is rendered artwork, not vector. Use the flat SVGs for print, embroidery, UI and anything under 96 px.
- Trademark clearance has not been checked. Run a search before registering.
