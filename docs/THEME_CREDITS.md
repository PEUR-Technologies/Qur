# Theme credits

Qur ships 17 built-in themes (`crates/qur_theme/themes/`). The TOML files are generated by `crates/qur_theme/tools/gen_themes.py` from each upstream palette, fetched on 2026-10-23. Every upstream license was checked in its repository and allows redistribution with attribution. The About window shows the same credits.

Qur Dark, Qur Light, High Contrast Dark and High Contrast Light are Qur's own (GPL-3.0-or-later, like the rest of Qur).

Notes:
- Gruvbox: `morhetz/gruvbox` has no LICENSE file. Its README and package.json declare MIT/X11 (Copyright (c) Pavel Pertsev), and the `gruvbox-community/gruvbox` fork carries the MIT text.
- Nord: the palette is from `nordtheme/nord` (MIT). The token mapping follows `nordtheme/visual-studio-code` (MIT).
- GitHub: colors are from `@primer/primitives@7.10.0` (MIT), mapped as in `primer/github-vscode-theme` `src/theme.js` (MIT).
- One Dark / One Light: Atom has no official terminal palette, so the ANSI colors are derived from the syntax hues.
- Qur adds the 6 agent accent colors, heat tints and some UI tokens to every theme. They are picked from each theme's own palette.

## Contrast adjustments

Qur requires 4.5:1 for body and secondary text, keywords, strings, functions and types. Comments and muted text need 3:1, and agent accents need 3:1 on the sidebar and editor (handoff 12a). Upstream colors that miss these were moved in lightness by the smallest step that passes. Hue and saturation are unchanged.
